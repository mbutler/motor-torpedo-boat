# Visual assets

`counters/*.png` are direct crops of the component sheet on PDF page 12 of the supplied `MTB.pdf`. Horizontal boat counters were rotated so the bow faces north. Their original drawings, colored bases, printed labels, and scan imperfections are retained. Transport art follows the selected transport card. No generated substitute boat artwork is used.

`water-chart.svg` is a new code-drawn nautical chart: repeated pen-style wave marks, coordinate grid, double ruled frame and compass rose. `paper.svg` supplies a restrained grain overlay for the interface and paper cards. These SVGs are supporting digital artwork rather than historical material.

Rendering keeps the exact existing counter footprints and hit geometry. Shadows, selection marks, wakes and labels are presentation only. Chart zoom changes CSS display size and preserves the game's world-coordinate input mapping.
